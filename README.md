# Spotify Clone – Flutter

A Spotify-inspired music streaming mobile application built with **Flutter and Dart**. This project aims to recreate Spotify's modern user interface and core music-listening experience while exploring Flutter development, responsive UI design, and music app functionality.


##  Features

- 🎨 **Modern UI** – Spotify-inspired dark theme and clean interface.
- 🏠 **Home Screen** – Discover featured music, albums, and playlists.
- 🔍 **Search** – Search for songs, artists, and albums.
- 🎵 **Music Player** – Play, pause, and control music playback.
- 📚 **Library** – Organize favorite songs, albums, and playlists.
- ❤️ **Favorites** – Save and access your favorite tracks.
- 📱 **Responsive Design** – Build a consistent experience across supported screen sizes.

*Features are subject to implementation progress.*

##  Tech Stack

- **Flutter** – Cross-platform mobile development framework.
- **Dart** – Programming language.
- **Material Design** – UI components and styling.
- **Git & GitHub** – Version control and project collaboration.

Additional technologies, such as Firebase, Supabase, or a music playback API, may be integrated as the project develops.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have installed:

- Flutter SDK
- Dart SDK (included with Flutter)
- Android Studio or Visual Studio Code
- An Android emulator or a physical device
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/kakanyero/spotify_clone.git
```

**2. Navigate to the project directory**

```bash
cd spotify_clone
```

**3. Install dependencies**

```bash
flutter pub get
```

**4. Check your Flutter environment**

```bash
flutter doctor
```

**5. Run the application**

```bash
flutter run
```
